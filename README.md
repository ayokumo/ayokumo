## Things I've built

### [Player Undervaluation Model](https://github.com/ayokumo/player_undervaluation_model) 🔨 *currently building*
Are players who move from outside Europe's top five leagues being undervalued by the market? I'm testing that using only data from before each transfer, with player stats in PostgreSQL and a LangChain scouting assistant that feeds into the model.
`Python` `SQL` `PostgreSQL` `LangChain`

### [Toronto Housing Analytics Platform](https://github.com/ayokumo/toronto-housing-project)
I wanted to know if Bank of Canada rate changes actually show up in Toronto shelter demand. I pulled five public sources into a tested dbt and DuckDB warehouse (433K row fact table, 26 automated tests) and found occupancy rose about 0.64pp for every 1% rate increase, roughly six months later.
`Python` `SQL` `dbt` `DuckDB` `statsmodels`

### [Toronto Shelter Overdose Spatial Analysis](https://github.com/ayokumo/toronto-overdose-spatial)
What actually predicts where overdoses happen across Toronto's 158 neighbourhoods? Using spatial models and machine learning on 2018 to 2025 data, low income prevalence turned out to explain most of the clustering, and I cut model error from 52 incidents down to 33.
`Python` `geopandas` `PySAL` `scikit-learn`

### [Premier League Match Predictor](https://github.com/ayokumo/pl-predictor)
A fully automated prediction pipeline that runs itself on GitHub Actions and updates a live dashboard, costing nothing to run. Built because I love football and wanted predictions I could actually explain.
`Python` `GitHub Actions` `REST APIs`
